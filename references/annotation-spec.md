# 标注条目格式规范

## 数据结构

每条标注为一个JavaScript对象，格式如下：

```javascript
{
  selector: '#wizSubmit',                          // 必填：CSS选择器或[data-anno-el-id="xxx"]
  summary: '提交任务创建，触发校验后弹出推送确认弹窗。',  // 必填：1-2句话说明用途
  detail: [                                         // 必填：业务规则/状态枚举/计算公式数组
    '校验规则：考试时长至少10分钟、及格分数0-100、考试总分恰好100分（如已生成）',
    '校验通过后弹出"创建成功"弹窗，包含"立即推送"和"稍后再说"两个选项'
  ],
  date: '05-28',                                    // 可选：更新时间（生成时自动填充）
  color: 'blue'                                     // 可选：标记颜色（生成时自动分配）
}
```

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `selector` | string | 是 | 元素的CSS选择器。优先使用ID选择器（`#id`），次选类选择器，最后使用 `[data-anno-el-id="xxx"]` |
| `summary` | string | 是 | 标注摘要，1-2句话说明该元素的功能和用途 |
| `detail` | string[] | 是 | 详细说明列表。每条一个业务规则/状态说明/计算公式。有PRD时从PRD提取原文 |
| `date` | string | 否 | 最后更新时间，格式 `MM-DD`，生成时自动填充 |
| `color` | string | 否 | 标记颜色，可选 `blue`/`orange`/`red`/`purple`，生成时按序号自动轮换 |

## 颜色轮换规则

标记点和详情卡片的颜色按如下顺序循环分配：

```
1 → blue    (#3B82F6)
2 → orange  (#F59E0B)
3 → red     (#EF4444)
4 → purple  (#8B5CF6)
5 → blue    (循环)
...
```

## 生成示例

### 完整标注模式（有PRD）

```javascript
{
  selector: '#tsKPICards .stat-card:nth-of-type(3)',
  summary: 'KPI-任务通过率：所有任务合格人数之和 ÷ 应参人数之和 × 100%。',
  detail: [
    '计算规则：sum(合格人数)÷sum(应参人数)×100%',
    '如果应参人数总和为0，通过率为0%',
    '颜色规则：≥60%绿色、30%-60%琥珀色、<30%红色'
  ],
  date: '05-29',
  color: 'orange'
}
```

### 纯原型分析模式（无PRD）

```javascript
{
  selector: '.task-list-area .btn-primary',
  summary: '新增任务按钮：点击进入培训任务创建向导。',
  detail: [
    '根据按钮位置和文本推断为新增操作入口',
    '按钮样式为主要按钮（primary），表明是页面主要操作'
  ],
  date: '05-29',
  color: 'blue'
}
```

## 标注内容优先级

生成标注内容时，按以下优先级获取信息：

1. **PRD文档原文**：直接引用需求文档中的业务规则、计算公式、状态说明
2. **统计字段说明文档**：引用专门的字段说明和计算公式文档
3. **HTML结构推断**：从元素的文本内容、class名称、位置关系推断功能用途
4. **模板化通用描述**：对无法推断的元素使用通用模板描述
